## About this repository

This repo doubles as the source code for my [live portfolio site](https://idrisverse-portfolio.vercel.app) — a Next.js + TypeScript + Tailwind CSS + Framer Motion single-page app, deployed on Vercel with auto-deploy on push to `main`.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build
npm run lint     # eslint
```

Source layout: `src/app` (routing/layout), `src/components/sections` (page sections), `src/lib/data.ts` (all site content — the single source of truth).
